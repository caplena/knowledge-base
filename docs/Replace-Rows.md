# Replace Rows

The Replace Rows function allows you to update existing rows in your dataset using a new upload — without losing manual coding or previously assigned topics. This is especially useful when you want to refresh your data while preserving your work.

📍 **When to Use Replace Rows**

The Replace Rows feature is helpful in several scenarios:

✅ **1. You want to add a new non-TTA column**

For example, adding a new demographic variable, metadata field, or custom tag that wasn't in the original dataset.

→ Use Replace Rows to introduce this column without reuploading everything from scratch.

✅ **2. You want to update values in a TTA column**

If you've corrected or enriched open-ended responses (TTA = Text To Analyze), you can replace those rows with the updated version.

→ This allows you to preserve existing coding.

✅ **3. You want to update values in a non-TTA column**

For example, fixing or completing values in columns like Gender, Age, or Brand.

→ Use Replace Rows to update those fields while keeping existing coding intact.

 **How to Replace Rows**

 ![Screenshot 2025-04-15 at 12.08.55.png](<../assets/images/Screenshot 2025-04-15 at 12.08.55.png>)


 - **Navigate to Your Project**

Go to the Data section of your project.Click the blue document icon on the left sidebar (📄) to access your dataset.

- **Click "Replace rows"**

In the top-right corner, click the Replace rows button.

 - **Upload Your New File**

Upload the CSV or Excel file that includes updated rows or new columns.

- **Match Columns**

In the matching screen:

![Screenshot 2025-04-15 at 14.23.11.png](<../assets/images/Screenshot 2025-04-15 at 14.23.11.png>)

- **Choose the identifier column (e.g., ID) that links existing rows to new data.**

> ⚠️ Important: If skipped, the system won't know which rows to replace and may treat them as new entries.

- **Ensure the new columns are aligned with your existing dataset.**

![Screenshot 2025-04-15 at 14.30.51.png](<../assets/images/Screenshot 2025-04-15 at 14.30.51.png>)

- **Validate and Finalize**

Click Validate to preview changes, then Finalize to apply the replacement.
